# 低空无人机运营管理平台

基于 **Vue 3 + TypeScript + Vite** 的低空经济无人机运营管理平台（纯前端演示系统），内置 Mock 数据与实时模拟引擎，无需后端即可运行。

## 技术栈

- Vue 3（Composition API + `<script setup>`）
- TypeScript
- Vite
- Pinia（状态管理 + 模拟引擎）
- Vue Router
- Element Plus（暗色主题）
- ECharts（图表）
- Canvas 自绘空域地图（无外部地图服务依赖，离线可用）

## 快速开始

```bash
npm install
npm run dev
```

浏览器访问 http://localhost:5173

其他命令：

```bash
npm run build       # 生产构建
npm run typecheck   # TS 类型检查
npm run preview     # 预览构建产物
```

## 功能模块

| 页面 | 功能 |
| --- | --- |
| 数据大屏 | 核心指标统计、空域态势地图（雷达扫描 / 禁飞区 / 航线 / 实时轨迹）、机队状态饼图、24h 飞行趋势、任务类型分布、告警玫瑰图、实时告警流 |
| 无人机管理 | 表格 / 卡片双视图、关键字 + 状态 + 机型筛选、分页、详情抽屉（遥测曲线 + 关联告警）、起飞 / 返航 / 充电 / 维护指令 |
| 飞行任务 | 任务列表（进度实时推进）、新建 / 编辑 / 删除、开始 / 暂停 / 恢复 / 终止、航线预览弹窗 |
| 实时监控 | 大屏地图 + 在线机队列表联动、单机遥测卡片与实时曲线、一键返航 |
| 告警中心 | 级别 / 状态 / 关键字筛选、单条处理（备注）、批量处理、清空已处理、跳转无人机详情 |

## 模拟引擎

`src/store/simulation.ts` 中的 Pinia store 每秒推进一次模拟：

- 无人机沿任务航线飞行（位置 / 航向 / 速度 / 高度 / 电量 / 信号实时变化）
- 任务进度自动推进，完成后无人机自动返航、充电
- 自动调度：待执行任务自动分派给空闲无人机
- 随机事件：低电量、信号弱、禁飞区入侵、强风、失联 / 恢复等告警
- 顶栏可暂停 / 恢复整个模拟

## 目录结构

```
src/
├── components/       # 通用组件（地图、统计卡、抽屉、任务表单）
├── composables/      # useECharts 封装
├── layout/           # 主布局（侧边栏 + 顶栏）
├── router/           # 路由
├── store/            # Pinia 模拟引擎
├── styles/           # 全局样式（暗色科技风）
├── types/            # TS 类型定义
├── utils/            # 格式化 / 状态映射
└── views/            # 五大页面
```
